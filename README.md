## 🧭 Overview

**Pathfinding Algorithm Visualizer** is an interactive educational tool that brings **Dijkstra's shortest path algorithm** to life. Draw walls, move start and end nodes, generate mazes, and watch the algorithm explore the grid with smooth, step-by-step animations in real time.

---

## ✨ Features

- 🎯 **Dijkstra's Algorithm** — Step-by-step visualization of shortest path discovery
- 🧱 **Wall Drawing** — Click and drag to create obstacles on the grid
- 🔀 **Draggable Nodes** — Move start and end points anywhere on the grid
- 🏗️ **Maze Generation** — Auto-generate random maze patterns
- 🎨 **Smooth Animations** — Color-coded exploration (visited, path, walls)
- 📱 **Responsive Grid** — Adapts to screen size
- 🔄 **Reset & Replay** — Clear board and re-run anytime

---

## 🎮 How to Use

| Action | Instructions |
|---|---|
| **Draw Walls** | Click & drag on empty cells |
| **Move Start/End** | Drag the green (start) or red (end) node |
| **Generate Maze** | Click the "Maze" button |
| **Visualize** | Click "Visualize" to run Dijkstra's |
| **Clear Board** | Click "Clear" to reset everything |

### Animation Legend

| Color | Meaning |
|:---:|---|
| 🟢 | Start node |
| 🔴 | End node |
| 🟦 | Visited / explored cells |
| 🟨 | Shortest path found |
| ⬛ | Wall / obstacle |
